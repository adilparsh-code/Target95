# Playwright Automation Skill

This skill enables browser automation using Playwright to interact with websites, fill forms, add items, and perform automated web tasks.

## Features
- Navigate to any URL
- Add items to todo lists
- Interact with web elements
- Capture screenshots
- Automate user workflows

## Usage
When invoked, this skill can:
1. Launch a browser instance
2. Navigate to the specified URL
3. Perform the requested interactions
4. Close the browser properly

## Example
- "Navigate to https://demo.playwright.dev/todomvc and add todo items"
- "Automate adding items to a todo list"
- "Interact with a web page to complete tasks"
