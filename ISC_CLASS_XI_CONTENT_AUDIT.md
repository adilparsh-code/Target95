# ISC Class XI Computer Science — Content Completion Audit

## Official structure

The ISC 2028 syllabus registry defines 13 Class XI topic clusters and a practical minimum of 15 Java assignments + 5 Python assignments + 1 project.

## Delivery rule

A topic is complete only when it has student-friendly learning objectives, concept notes, MCQs with explanations, graded practice, and practical/programming work appropriate to the topic.

## Practical target

The Class XI work will exceed the minimum assignment count rather than stopping at the minimum: at least 20 Java practice/programming tasks plus 8 Python tasks are planned, with one integrated project brief.

## Quality bar

The official syllabus is the baseline, not the ceiling. Content will favour conceptual reasoning, tracing, debugging, application and exam-style practice over bulk low-quality question generation.
