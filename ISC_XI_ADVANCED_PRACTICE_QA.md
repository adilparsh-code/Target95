# ISC XI Advanced Practice QA

## Completed focus areas
- Inheritance: constructor order, field hiding, `super`, overriding, code reuse.
- Polymorphism: overloading vs overriding, runtime dispatch, reference vs object type.
- Recursion: base case, recursive progress, tracing, stack unwinding, debugging.
- Stack: LIFO, push/pop/peek, overflow/underflow, array implementation.
- Queue: FIFO, enqueue/dequeue, underflow, linear vs circular reuse.
- Output/tracing: loops, nested loops, break, methods and primitive parameter passing.
- 2D arrays: row sums, column sums, row maxima, row-wise sorting, diagonals, prime-per-row, max row/column.

## Quality rules
- Questions are fresh and are not Class X/XI question copies with renamed variables.
- Include explanation/reasoning for concept and tracing questions.
- Difficulty progresses from foundation to challenge without trick wording.
- Rectangular 2D-array questions explicitly distinguish `matrix.length` from `matrix[0].length`.
- Data-structure questions include implementation-level reasoning, not just definitions.

## Student-facing integration requirement
The data pack must be wired into the ISC XI learning/question pages before the area is considered production-complete.
