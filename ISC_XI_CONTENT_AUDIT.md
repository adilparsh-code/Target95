## Practical requirement

The syllabus registry states a minimum of **15 Java assignments + 5 Python assignments + 1 project**. Target95 should exceed the minimum with graded, non-duplicate practicals.

## Product standard

For every topic, Target95 should aim for:
- student-friendly learning objectives and explanations;
- key concepts and common mistakes;
- graded MCQs with explanations;
- output/tracing/debugging questions where applicable;
- programming/practical tasks where applicable;
- exam-style application questions;
- discoverable integration with the existing study/question architecture.

## Execution order

1. Section A foundation: numeration, encodings, logic/hardware.
2. Section B Java core: OOP through methods/constructors.
3. Arrays/strings and I/O/file handling.
4. Python.
5. Trends and ethics.
6. Final coverage audit and practical-count QA.

No route or UI architecture changes are part of this foundation phase.
