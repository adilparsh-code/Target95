# ISC Class XI Project — Student Performance Management System

## Goal
Build a Java console application that stores student academic data and produces useful performance reports.

## Required concepts
- Classes and objects
- Constructors
- Methods
- Arrays
- Strings
- Searching and sorting
- Input validation
- Appropriate primitive/wrapper usage

## Core features
1. Add student records.
2. Display all records.
3. Search by roll number.
4. Calculate total, average and grade.
5. Identify highest/lowest performer.
6. Sort records by marks.
7. Generate a student report.
8. Validate invalid input.

## Student workflow
Plan classes → define fields → design constructors → implement methods → test with sample data → add search/sort → handle edge cases → prepare viva.

## Minimum test cases
- Empty record set
- One student
- Multiple students
- Equal marks
- Invalid marks
- Search hit and search miss
- Highest/lowest tie

## Viva prompts
- Why did you choose these classes?
- Why use a constructor?
- Which method calculates the grade?
- What happens when the roll number is not found?
- Which sorting/searching approach did you use and why?

## Extension challenges
- Add subject-wise marks.
- Add attendance percentage.
- Add a topper report.
- Export a text report.

## Rule
Do not submit copied/generated code without understanding it. Students should be able to explain every class, field, constructor, method and algorithm used.
