# ISC Class XI Question QA Rules

## Core rule
Class XI may reuse foundational concepts that naturally overlap with Class X, but the question bank must not become a Class X copy.

## Required standards
- Every XI topic must have fresh, chapter-specific questions.
- Do not reuse Class X wording, examples, numbers, code snippets or answer choices unless the notation itself is unavoidable.
- Increase XI difficulty through tracing, reasoning, application, debugging, output prediction and multi-step problems.
- Keep questions within official ISC XI scope; clearly label useful extensions.
- Every MCQ needs a correct answer and explanation.
- Programming/practical questions must match the chapter and ISC XI Java/Python context.
- Do not inflate counts with trivial duplicates.

## Overlap handling
For shared concepts such as arrays, strings, OOP basics and methods, the XI version should deliberately move beyond Class X recall into edge cases, tracing, debugging, design and application.

## Project rule
The Class XI project is part of completion. Students should build and explain the project rather than submit an unexplained code dump.
