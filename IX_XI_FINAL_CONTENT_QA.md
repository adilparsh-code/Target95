## XI advanced coverage
- Inheritance: constructor order, `super`, field hiding, debugging, programming.
- Polymorphism: overloading vs overriding, runtime dispatch, reference-type visibility.
- Recursion: base case, call/return tracing, stack unwinding, debugging, programming.
- Stack: LIFO, push/pop/peek, overflow/underflow, array implementation.
- Queue: FIFO, linear vs circular queue, underflow, implementation.
- Output/tracing: loops, methods, recursion, objects.
- 2D arrays: row/column sums, row maxima, row conditions, diagonal comparison, row sorting, rectangular-array indexing.
