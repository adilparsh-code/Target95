# Roadmap

Target95+ Product Roadmap

This document outlines the planned features and improvements for Target95+. We follow [Semantic Versioning](https://semver.org/) and release major versions quarterly.

## 🎯 Current Version: v1.0 (Released - January 2025)

### Status: ✅ Production Ready

Target95+ is now live and serving ICSE & ISC Computer Science students with core features.

#### Completed Features
- ✅ Mock test system with analytics
- ✅ Practice question bank with filters
- ✅ AI Tutor integration
- ✅ Study material and notes
- ✅ Progress tracking dashboard
- ✅ Daily challenges
- ✅ Rewards and gamification
- ✅ User authentication (Email/Password, Google)
- ✅ Bookmarks system
- ✅ Offline support (PWA)
- ✅ Responsive design
- ✅ SEO optimization
- ✅ Firebase integration
- ✅ Vercel deployment

## 🎯 How We Prioritize

Features are prioritized based on:

1. **User Impact** - How many users will benefit?
2. **Learning Value** - Does it improve learning outcomes?
3. **Technical Feasibility** - Can we build it well?
4. **Strategic Alignment** - Does it fit our mission?
5. **Community Demand** - How many requests do we get?
