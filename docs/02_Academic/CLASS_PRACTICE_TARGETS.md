# Target95 Class-wise Practice Targets

## Class IX
Each official topic must have theory questions, MCQs, output tracing where applicable, programming questions for Java topics, common-mistake questions, revision drills, and mixed chapter practice.

Programming focus: fundamentals, input/data processing, conditionals, loops, nested loops, patterns and beginner OOP.

## Class X
Each official topic must have stronger board-style programming practice, including arrays, strings, methods, constructors, library classes and integrated problems, plus theory/MCQ/output/PYQ-style practice.

Programming focus: array algorithms, matrix programs, string processing, method-driven programs, class/constructor problems, searching/sorting and integrated ICSE-style problems.

## ISC XI
Practice must cover the verified 2028 syllabus across Hardware, Java, Python and conceptual/ethical areas. Java and Python sections require substantial programming pools and output tracing.

## ISC XII
Practice must cover the verified 2028 syllabus including Boolean Algebra, logic gates, SOP/POS, minterms/maxterms, K-maps, combinational circuits and all other official Java/Python/data-structure topics. Include theory, derivations/simplification, circuit reasoning, programming, output tracing, PYQ-style and full mock-test practice.

## Cross-class quality rules
- No invented syllabus topics.
- No generic filler prompts.
- No duplicate questions with superficial wording changes.
- Every question tagged with class, board, chapter, topic, type and difficulty.
- Every programming question must have a precise task and expected result; solutions are added only after validation.
- Practice content must be traceable back to the verified syllabus.
