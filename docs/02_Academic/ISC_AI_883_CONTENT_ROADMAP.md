# ISC Artificial Intelligence (883) — Content Roadmap

**Examination Year:** 2027  
**Board:** ISC / CISCE  
**Subject Code:** 883

## Purpose

This roadmap keeps ISC Artificial Intelligence theory, practice questions, practical work and projects separate. It is an implementation checklist for Target95 and must remain aligned to the official CISCE syllabus.

## Question-bank requirements

Each unit should ultimately contain:

- Board-style MCQs
- Assertion–Reason questions
- Short-answer and structured questions
- Case-based/application questions
- HOTS questions
- Numerical/worked problems where applicable
- Practical/programming-oriented questions where applicable
- Answer keys and concise explanations
- Marks and difficulty metadata

## Separation rules

1. ISC AI **883** must not be mixed with CBSE AI **843/402** content.
2. ISC AI theory must remain separate from project/practical entries.
3. Class XI and Class XII content must remain separately addressable.
4. Do not mark a unit complete merely because a heading or navigation page exists; completion requires teaching content and appropriate assessment coverage.
5. Syllabus claims must be checked against the official CISCE source before final validation.

## Delivery order

1. Expand chapter-wise theory.
2. Add worked examples and practical understanding.
3. Add board-style assessments.
4. Add case/HOTS/application practice.
5. Add practical/programming coverage.
6. Validate answer keys, marks and syllabus mapping.
7. Verify production build/deployment.
