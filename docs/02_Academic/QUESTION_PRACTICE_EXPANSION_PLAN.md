# Target95 Question & Practice Expansion Plan

## Goal
Expand every syllabus chapter with a large, board-aligned practice pool rather than placeholder questions.

## Required per chapter
- Conceptual/theory questions
- MCQs with explanations
- Output-tracing questions
- Programming questions with difficulty bands
- Previous-year-style questions tagged by marks and topic
- Short-answer and long-answer questions
- Common-mistake remediation questions
- Mixed practice sets
- Revision drills

## Programming question bands
- Easy: syntax, direct application, one-concept programs
- Medium: multi-step logic, nested conditions/loops, arrays/strings/methods
- Hard: integrated board-style problems, edge cases, algorithmic reasoning

## Practice engine requirements
- Chapter filter
- Topic filter
- Difficulty filter
- Question-type filter
- Random practice set
- Timed practice
- Retry incorrect questions
- Explanations after submission
- Progress persistence
- Score and accuracy tracking
- Weak-topic identification

## Quantity target
The project should grow toward a large question bank across Classes IX-XII. Quantity must never replace quality: every question must be syllabus-relevant, technically valid, duplicate-checked, and appropriate to the class level.

## Quality gate
No question should be treated as complete when it contains generic filler such as “write a program using this topic”. Programming questions must specify the task, required inputs/outputs, constraints where needed, and board-appropriate expectations.
