## Evidence required for each practical

Record the author of the problem statement, algorithm, source code, sample input and output; any source used for factual checking; the exact URL/publication and license or permission where applicable; the reviewer and date; and any independent rewriting performed.

Standard language syntax, basic programming ideas and algorithms are not claimed as exclusive expression. Distinctive wording, examples, diagrams and solution presentation must not be copied. Unknown provenance remains unresolved until evidence is recorded.
