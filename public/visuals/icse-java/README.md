# ICSE Java Visual Assets

These SVG assets are student-facing educational visuals for ICSE/ISC Java chapter content.

The assets are rendered through the existing `DiagramsSection` using `next/image` and are referenced from chapter-content `diagrams` records.

Current assets:
- `java-platform-stack.svg`
- `java-program-life-cycle.svg`
- `java-array-indexing.svg`
- `java-inheritance-hierarchy.svg`
- `java-loop-flow.svg`
- `java-encapsulation-flow.svg`

All visuals are designed as accessible, version-controlled SVGs rather than decorative images.
