## Acceleration rules

1. Do not block the whole CBSE programme on completion of one class.
2. Verify all eight class/subject tracks at source level before deep chapter mapping.
3. Batch detailed content mapping by subject code so XI/XII work is completed together.
4. Keep 083 and 065 Python tracks separate from 802 Java.
5. Keep 402 independent of both Python and Java assumptions.
6. Map Target95 chapters/question banks/mocks only after the corresponding official 2026–27 unit is verified.
7. Never mark a track complete merely because unit names or source URLs exist.

## Current known facts

- 083 Computer Science is Python-based; Class XII includes functions, exception handling, files, stacks, networks, databases/SQL and Python-SQL connectivity.
- 065 Informatics Practices explicitly includes Python, databases/SQL, and emerging trends in XI; XII includes Pandas/Matplotlib, SQL, networks and societal impacts.
- 802 Information Technology is a separate skill-subject track and includes Fundamentals of Java in XI and Java in XII.
- 402 Information Technology is a separate skill-subject track and must not inherit programming assumptions from 083/065/802.

## Definition of complete

A track is COMPLETE only when its official 2026–27 units, learning outcomes/theory/practical scope, Target95 chapter mapping, question-bank coverage and mock/assessment coverage have all been checked and any gaps are resolved or explicitly documented.
