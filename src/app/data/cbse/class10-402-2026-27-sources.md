## Book/support-material policy

1. The 2026–27 official syllabus remains authoritative.
2. CBSE books and support material are mapped as secondary learning resources.
3. Older-session books/material are not treated as proof that a topic belongs to the 2026–27 syllabus.
4. If textbook content and current syllabus differ, the current syllabus wins.
5. No Python content is inferred or imported into Class X IT 402.
6. Legacy Target95 Class X files must not be used as curriculum source-of-truth unless individually verified against the 2026–27 syllabus.

## Legacy-data audit

Known legacy risks observed in the repository:

- Legacy Class X file described an outdated 'Computer Applications' structure.
- Legacy content referenced code 165 alongside 402.
- Legacy chapter/unit counts and marks were from an older curriculum model.
- Legacy summaries contained old office-tool/web/programming groupings not matching the current 2026–27 402 structure.

Therefore the legacy Class X structure is **not** used as the current 2026–27 curriculum source.

## Current 2026–27 subject-specific structure

- Unit 1 — Digital Documentation (Advanced) using LibreOffice Writer
- Unit 2 — Electronic Spreadsheet (Advanced) using LibreOffice Calc
- Unit 3 — Database Management System using LibreOffice Base
- Unit 4 — Maintain Healthy, Safe and Secure Working Environment

## Final audit rule

A Class X 402 topic is considered verified only when it can be traced to the current 2026–27 CBSE syllabus or an official current-session CBSE support resource.
