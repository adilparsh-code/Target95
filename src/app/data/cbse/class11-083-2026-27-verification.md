## Scope
This track is strictly separate from Informatics Practices (065) and Information Technology (802). Python is the core programming language for 083. No Pandas/Matplotlib library mapping is included here unless explicitly prescribed by the 083 syllabus.

## Unit structure

### Unit 1 — Computer Systems and Organisation
Weightage: 10 marks
Coverage includes: computer system overview; basic computer organisation; software; operating system concepts; data representation; encoding; Boolean logic and related foundations as specified by the current syllabus.

### Unit 2 — Computational Thinking and Programming – I
Weightage: 45 marks
Python is the core programming component.

Verified topic groups to map exactly from the current 2026–27 PDF before question generation:
- problem solving and computational thinking
- Python programming environment and fundamentals
- Python tokens, variables, data types and operators
- expressions and input/output
- conditional execution
- iteration and control flow
- strings
- lists
- tuples
- dictionaries
- functions
- debugging/testing concepts where prescribed

### Unit 3 — Society, Law and Ethics
Weightage: 15 marks
Coverage includes cyber safety/security, intellectual property and copyright-related concepts, privacy and responsible use, digital society issues, and ethical/legal considerations as prescribed by the current syllabus.
