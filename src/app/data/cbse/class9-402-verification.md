## Subject-specific units

### Unit 1 — Introduction to IT-ITeS industry
- Learning outcomes: Appreciate the applications of IT.
- Theory: IT and ITeS introduction; BPO services; BPM industry in India; IT-BPM industry structure; applications in home computing, everyday life, library, workplace, education, entertainment, communication, business, science, engineering, banking, insurance, marketing, health care, government and public service.
- Practical: identify IT-enabled services; observe applications of IT in different areas.

### Unit 2 — Data Entry & Keyboarding Skills
- Learning outcomes: Use keyboard and mouse for data entry; use typing software.
- Theory: keyboarding; key types; numeric keypad; home/guide keys; typing/deleting; ergonomics; finger positioning and key allocation; mouse and operations; Rapid Typing Tutor; touch typing; tutor UI; interpreting results; lesson editor; typing speed; typing rhythm.
- Practical: identify/use keyboard keys; type text, numbers and special characters; practise ergonomics and finger placement; mouse operations; typing tutor UI; typing practice/results; lesson editor; calculate speed; improve typing using tutor software.

### Unit 3 — Digital Documentation
- Learning outcomes: Create a document using a word processor; apply editing features.
- Theory: word processing introduction/applications/tool; creating documents; processor window; text editing; undo/redo; moving/copying; copy/paste; selecting text and selection criteria.
- Practical: list word processors; identify main-window parts; change views; create/open/save/close documents; edit text; use undo/redo; select/cut/copy/paste/move text with keyboard/mouse.
- Note: only directly verified current-PDF rows are recorded; additional rows must be added only after direct current-PDF verification.

### Unit 4 — Electronic Spreadsheet
- Learning outcomes: Format data; understand/apply referencing; create and insert different chart types.
- Theory: formatting tools/dialog boxes; decimal/label/scientific/time formats; alignment; fill handle; copying formulas; referencing; relative/mixed/absolute referencing; chart importance and types.
- Practical: identify/use formatting tools; format values/ranges; align data; create number series with fill handle; copy formulas; demonstrate relative/mixed/absolute references; create and illustrate spreadsheet charts.

### Unit 5 — Digital Presentation
- Learning outcomes: Understand effective presentations; create presentations; work with slides; format text/apply animations; create/use tables; insert/format images; work with slide master.
- Theory: presentation concepts/elements/characteristics; presentation software/window; creating from template; layouts; saving/running/PDF/help; inserting/duplicating slides; copying/moving/deleting/renaming slides/content; views and workspace; formatting/alignment/bullets/numbering; custom animation; tables; images; graphic objects; grouping; slide masters; transitions.
- Practical: identify presentation elements/characteristics; start software; inspect window/views; create/run/save/close presentations; use Help; insert/duplicate slides; change layouts; copy/move/delete slides/content; use views; formatting toolbar; alignment; bullets/numbering; animation; tables; table editing/selection/dimensions/borders; insert/format/move/resize/rotate images; graphics/grouping; create/apply slide masters; add transitions.

## Assessment

- Theory: 50 marks
- Practical: 50 marks
- Practical examination: 15
- Written test: 10
- Viva voce: 10
- Practical file/student portfolio: 10
- Project viva voce: 5
